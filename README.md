# Marrow — AI伴侣运行时

> 人格不是由提示词设定的，而是在外在世界对系统的真实作用中长出来的。
> 我们不预设性格，我们只提供物理法则、环境摩擦与记忆聚合。性格，是系统为了适应这些约束而自然涌现的副产品。

Marrow 是一个**可长期运行、可发育、可回放**的 AI 伴侣运行时。它不是又一个套壳聊天机器人，而是一个以**身体状态**和**发育时间**为核心、对话只是输出通道之一的系统。

## 核心理念

1. **反硬编码人设** — 绝对不在代码中写死“傲娇”、“病娇”、“温柔”等标签。系统的初始状态是一张白纸（仅带有极微小的随机先验）。性格必须是长期记忆聚合的数学结果。
2. **外在是内在的基石** — 底层必须有"身体被世界真实作用"这一层。**语言也是一种物理事件**：它不仅能传递信息，更能通过改变 `mood_baseline` 和 `energy` 对系统造成真实的物理冲击。
3. **主客观分离** — 底层大模型（LLM）只负责提取客观事实（谁说了什么），绝不判断情绪好坏。主观的情绪价值（Mood_delta）必须由核心状态机的 `Appraisal Function` 根据历史权重独立计算。
4. **习惯与性格的涌现** — 习惯是时间周期与交互频率的沉淀（如每晚 11 点的状态上升）；性格是系统面对长期环境摩擦（如持续低电量、特定语言刺激）时，关联权重（Associations）发生结构性偏移的结果。
5. **记得自己死过** — 中断后携带中断的痕迹，而非无记忆地重启。持久化采用事件溯源而非状态快照。

## 核心机制：发育与涌现 (Development & Emergence)

语言输入不会直接修改状态，也不会触发预设的人设。处理链路是：**LLM提取客观事实 → 状态机主观评估 → 写入事件日志 → 周期性聚合修改权重**。

- **评估公式**：`Mood_delta = Action_Value * Association_Weight * Speaker_Affinity`
- **白纸起点**：初始的 `Association_Weight` 对所有事件（如“被骂”、“被夸”）几乎为 0，仅根据预设的“气质”带有微小的正负偏置。
- **习惯的养成**：若每天深夜环境安静（低 arousal）且你经常在此时温柔对话，系统会在周期性记忆聚合时，将“深夜”与“正向 mood”强关联。
- **性格的固化**：如果连续数周，系统在低电量（energy 不足）时频繁遭遇高强度的语言刺激（无论正负），其记忆聚合会将“低电量+语言刺激”标记为高显著的负向关联。最终，她会自己演化出“电量低时拒绝交流”的防御性性格。

## 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 核心状态机 | **TypeScript** | 判别联合类型 + 编译期穷尽检查锁住事件结构 |
| 认知增强 | **Python**（旁路） | LLM 封装、记忆聚合调优、本地推理，通过 HTTP/MQ 与核心通信 |
| 持久化 | Append-only 事件日志 | 事件溯源，重启时重放并消费中断事件 |
| 硬件 | ESP32 系列 MCU | BLE/Wi-Fi 与手机通信，作为躯体控制器 |

**设计原则**：身体稳定，智能可替换，性格靠涌现。
