# Marrow — AI伴侣运行时

> 人格不是由提示词设定的，而是在外在世界对系统的真实作用中长出来的。

Marrow 是一个**可长期运行、可发育、可回放**的 AI 伴侣运行时。它不是又一个套壳聊天机器人，而是一个以**身体状态**和**发育时间**为核心、对话只是输出通道之一的系统。

## 核心理念

1. **外在是内在的基石** — 底层必须有"身体被世界真实作用"这一层，上层人格才有要突破的对象。
2. **有限性与脆弱性是人格养料** — 续航耗尽、碰撞中断、温度变化，这些不是传感器读数，而是会改变运行状态的不可协商事件。
3. **成功标准是涌现性，不是稳定性** — 期望它做出"没预料到但事后觉得合理"的行为。
4. **记得自己死过** — 中断后携带中断的痕迹，而非无记忆地重启。持久化采用事件溯源而非状态快照。

## 架构概览

```
┌─────────────────────────────────────────┐
│           输出通道（对话/语音/行为）        │
│   LLM 输出 = 候选行为，经状态机过滤后放出   │
├─────────────────────────────────────────┤
│            状态机核心（TypeScript）        │
│   energy · mood_baseline · arousal       │
│   interruption_flag（不可被对话层覆盖）     │
├─────────────────────────────────────────┤
│         记忆层（分层聚合，非单一体文本）     │
│   情景记忆缓冲区 → 关联权重表 → 遗忘/覆盖   │
├─────────────────────────────────────────┤
│      持久化：Append-only 事件日志          │
│   每一次状态变化写一条事件，中断也是事件     │
├─────────────────────────────────────────┤
│        环境与躯体（传感器 / MCU / 续航）    │
└─────────────────────────────────────────┘
```

## 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 核心状态机 | **TypeScript** | 判别联合类型 + 编译期穷尽检查锁住事件结构 |
| 认知增强 | **Python**（旁路） | LLM 封装、记忆聚合调优、本地推理，通过 HTTP/MQ 与核心通信 |
| 持久化 | Append-only 事件日志 | 事件溯源，重启时重放并消费中断事件 |
| 硬件 | ESP32 系列 MCU | BLE/Wi-Fi 与手机通信，作为躯体控制器 |

**设计原则**：身体稳定，智能可替换。

## 当前阶段

🚧 **阶段一：最小状态机**（不接 LLM、不接传感器）

- 每 10 秒 tick，energy 衰减、mood_baseline 漂移、arousal 指数衰减
- 规则映射输出行为风格
